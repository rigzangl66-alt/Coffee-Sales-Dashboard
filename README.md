
# Coffee Sales Dashboard
## Project Overview

This project is an interactive Excel dashboard that analyzes coffee sales data, customer purchasing patterns, and sales performance across different countries.
## Tools & Skills

	•	Microsoft Excel

	•	Data Cleaning and Preparation

	•	XLOOKUP and Excel Formulas

	•	PivotTables and PivotCharts

	•	Data Visualization

	•	Slicers and Timeline

	•	Dashboard Design
## Dashboard Features

	•	Coffee Sales Over Time: Displays monthly sales trends for different coffee types.

	•	Sales by Country: Compares sales performance across the United States, Ireland, and the United Kingdom.

	•	Top 5 Customers: Identifies the five highest-spending customers.

	•	Interactive Filters: Allows users to filter sales data by roast type, product size, loyalty card status, and order date.
## Learning Outcomes

Through this project, I gained hands-on experience in working with Excel datasets, using formulas, creating PivotTables, analyzing sales data, and building an interactive dashboard.
